# Frode sin bygg marketplace

Personleg plugin marketplace med pluginen ol-agentane, som inneheld fire ferdigheiter for oppdragsleiar i bygg og anlegg: redaktoren, faktasjekkaren, prosjektleiaren og ICE moteplanleggjaren.

## Slik installerer du i Cowork

1. Last opp heile denne mappa til eit nytt GitHub repo. Eit privat repo held om du vil ha det for deg sjolv.
2. Opne Claude Desktop og ga til Cowork.
3. Opne Customize menyen og velg fana Plugins.
4. Under Personal plugins, klikk plussknappen og velg Add marketplace.
5. Lim inn lenkja til GitHub repoet ditt og legg det til.
6. Installer pluginen ol-agentane fra marketplacen.

Etter installasjon slar ferdigheitene inn automatisk nar dei er relevante. Du kan ogsa be om dei direkte.

## Krav
Cowork krev eit betalt abonnement og Claude Desktop appen. Cowork og Skills ma vere pa for organisasjonen din om du er pa Team eller Enterprise.

## Validering
Vil nokon med Claude Code sjekke strukturen, kan dei kjore: claude plugin validate plugins/ol-agentane/.claude-plugin/plugin.json
